## 🚀 Getting Started Locally

### Prerequisites
- Node.js (version 18 or higher)
- npm, yarn, or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Akash-R-tech/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) or the port indicated in your terminal.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The production-ready assets will be compiled into the `dist/` directory.

## 🌐 Deploying to Vercel

This repository is pre-configured with `vercel.json` for 1-click deployment.

### Method 1: Via Vercel Dashboard (Recommended)
1. Push this repository to your GitHub account.
2. Visit [vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Click **Deploy**. Vercel will build and publish your portfolio in under a minute!

### Method 2: Via Vercel CLI
```bash
npx vercel
```
Follow the interactive terminal prompts to deploy immediately.
